# THE CARWSOME WEBSITE
# COMP501 – Autonomous Vehicles Website Project

## Project Overview

This project explores the ethical, social, technical, environmental, and economic impacts of Autonomous Vehicles (AVs) and Artificial Intelligence in Transportation.

The website was developed as part of the COMP501 assessment and includes research into:

* Opportunities of autonomous vehicles
* Risks and ethical concerns
* Technology choices and decision-making
* Future implications for society
* References and supporting research

The website was created using HTML, CSS, and JavaScript.

---

## How to Run the Project

1. Download and extract the ZIP folder.
2. Open the project folder.
3. Start the website by opening:

index.html

This is the official start page of the project.

## Easter Egg  – The Legend of Gerald

During the development of this project, a mysterious frog suddenly appeared. No one knows exactly where he came from, but he quickly became part of the team.

We named him Gerald.

Gerald is now the unofficial mascot of this project. He is not just decoration — he is a vibe, a presence, and possibly the true project manager.

If you explore the website carefully, you can discover Gerald’s hidden sanctuary by going into the Settings page and clicking:

“I like Frogs 🐸”

This unlocks a secret page dedicated entirely to Gerald, celebrating his contribution to the project (mostly moral support and watching silently).

Some say Gerald appears more often when the code is working… others say he causes it to work. His role remains scientifically unconfirmed.
